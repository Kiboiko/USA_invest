ТЗ ДЛЯ АГЕНТСКОГО КОДИРОВАНИЯ
1. Задача

Разработать двухстраничную web-воронку по предоставленным визуальным референсам.

Структура:

PRELAND → LANDING → отправка формы → Google Sheets

Нужно получить визуально цельный проект, похожий по общей композиции и уровню исполнения на референсы, но не копировать бренд BBC и не выдавать страницу за настоящий новостной ресурс.

Основная задача проекта: собрать современный адаптивный preland в формате финансовой/деловой новости и основной landing page финансового сервиса.

2. Стек

Использовать:

React
TypeScript
Vite
Tailwind CSS
Lucide React или аналогичные SVG-иконки
обычный fetch для отправки формы
Google Apps Script Web App как endpoint для Google Sheets

Не использовать тяжёлый backend.

Не использовать базу данных.

Не использовать Redux, если для него нет реальной необходимости.

Код должен быть простым для дальнейшей поддержки.

3. Структура проекта

Предпочтительная структура:

Контент не размазывать по JSX.

Тексты, изображения, ссылки и настройки вынести в data/config.
